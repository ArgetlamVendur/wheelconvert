# winget manifest (DRAFT, not submitted)

These files are a draft for a future submission to `microsoft/winget-pkgs`. Nothing here has been submitted or validated with `winget validate`.

Before submitting, the user must:
- replace every `PLACEHOLDER` value (publisher, version, URL, SHA-256),
- make the GitHub repository public and publish a non-draft release,
- fill in `InstallerSha256` from the release's `SHA256SUMS.txt`,
- check winget's rules on unsigned installers at submission time.
