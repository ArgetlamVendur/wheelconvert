## Findings
1. **tests/WheelConvert.App.Tests/HotkeyParserTests.cs:261-283: Start/register/unregister path is untested.** The two trigger tests never reach `RegisterHotKey` (invalid string fails at parse; the idempotency test never calls `Start`). Fix: add an STA test (`[StaFact]`-style, or a thread with `ApartmentState.STA` and a Dispatcher-free message pump) that does `Start()` with a rarely used hotkey, asserts true, disposes, then starts a second trigger with the same hotkey and asserts true (proves unregister). Also a taken-hotkey test: two live triggers, second returns false with "already used by another app". Fall back to a documented manual check if CI cannot do it.
2. **tests/WheelConvert.App.Tests/WheelConvert.App.Tests.csproj:14-17: new packages (xunit 2.5.3, Microsoft.NET.Test.Sdk 17.8.0, xunit.runner.visualstudio, coverlet.collector 6.0.0) have no ADR-010 row** (AGENTS.md §4.8 / ADR-010). Fix: add rows with licence check (xunit Apache-2.0, Test.Sdk MIT, coverlet MIT) in this PR. Also, AGENTS.md says "latest stable"; the pinned versions are old, so confirm or update. Coverlet is not needed by any WP; drop it (§4.9).
3. **HotkeyTrigger.cs:91: `LastError` embeds `ex.Message`.** Contract C3 and AGENTS.md §6 ask for plain-language text with no stack/exception detail. Fix: use a fixed message such as "Couldn't start the hotkey. Try a different one in settings." Minor.
4. **HotkeyTrigger.cs:34-36: `#pragma warning disable CS0067` on `WheelDismissRequested`.** Acceptable, since `ITrigger` demands the event and this trigger intentionally never raises it; the comment is slightly misleading ("WP-11 manages closing") but not wrong. Optional: say "never raised by design (WP-03 req. 4)".
5. **HotkeyTrigger.cs:132-134: if `GetCursorPos` fails the wheel opens at (0,0).** Corner case, rare. Better to skip raising, or note it. Optional.
6. **HotkeyTrigger.cs:100-114: `Stop()` must run on the thread that called `Start()`** (`UnregisterHotKey` is thread-affine; the HwndSource is also thread-bound). Fine for WP-11 (UI thread), but add a one-line doc comment so it isn't called from a thread-pool exit path. Optional.
