# Checkpoint 1 — Core and contracts

**Reviewer:** independent Claude agent (did not write the code), 2026-10-20
**Scope:** `src/WheelConvert.Core/**`, `tests/WheelConvert.Core.Tests/**`, `docs/CONTRACTS.md`
**Verdict:** CHANGES NEEDED → all BLOCKER/MAJOR findings fixed (below); re-verified by the next checkpoint.

Each fix has a regression test in `tests/WheelConvert.Core.Tests/ReviewRegressionTests.cs` (named `F<nn>_…`).

| # | Sev | Finding | Fix |
|---|---|---|---|
| 1 | BLOCKER | PDF→PDF operations hidden as "already PDF": the whole PDF module unreachable | `ConversionTarget.IsFormatChange` + `IsRedundantFor`; PDF edit targets set `false` |
| 2 | MAJOR | `CancelAll` didn't cancel queued jobs (token read at dequeue) | Token captured at enqueue (per-job CTS linked to the current generation) |
| 3 | MAJOR | `DisposeAsync` could leave jobs without `JobCompleted`; `WhenIdle` hung (2/300) | Workers drain after the writer completes; leftovers end `Cancelled`; 5 s bounded shutdown; 150-iteration stress test |
| 4 | MAJOR | No progress path from converters | `JobProgress` event, throttled `IProgress<double>` per job |
| 5 | MAJOR | No per-job cancel, no batches | `Cancel(jobId)`, `EnqueueBatch` → `BatchHandle`, `BatchCompleted`, `BatchId` on events |
| 6 | MAJOR | Converters couldn't read the output label | `OptionKeys.OutputLabel`, `ConversionRequest.OutputLabel` |
| 7 | MAJOR | Partial results lost on failure | `Fail(error, message, committedPaths)`; queue attaches committed paths on crash/cancel |
| 8 | MAJOR | Temps leaked when a converter crashed/cancelled | Per-job `JobOutputScope` discards uncommitted temps when the job ends |
| 9 | MAJOR | `Discard` deleted any `.~wc-*` file (a user's own file too) | Writer only commits/discards paths **it issued**; strict name pattern; `TryDeleteStaleTemp` for start-up clean-up |
| 10 | MAJOR | `Commit` accepted temps from other folders (non-atomic cross-volume move) | Temp must be issued for the source's folder |
| 11 | MAJOR | Transient lock on settings → quarantined + overwritten with defaults | Quarantine only on invalid JSON; locked file → defaults in memory, `SavesBlocked`, `Save` refuses |
| 12 | MAJOR | One bad field reset every setting; PascalCase ignored | Per-property tolerant parsing, case-insensitive names |
| 13 | MINOR | Non-durable save, fixed temp name, quarantine name collisions | Flush to disk, `File.Replace`, unique temp, GUID in quarantine name |
| 14 | MAJOR | `Kill(entireProcessTree)` `AggregateException` escaped | Caught |
| 15 | MINOR | Unbounded second `WaitForExit`; orphan if setup after `Start` failed | Removed; kill on any post-start failure |
| 16 | MINOR | FFmpeg flags / encoding not in contract | CONTRACTS C9 updated |
| 17 | MINOR | `CancelAll` ran callbacks on caller thread; disposed CTS early; threw after dispose | Cancels off-thread; generations disposed with the queue; no-op after dispose |
| 18 | MINOR | Two different exceptions for enqueue-after-dispose | Always `ObjectDisposedException` (write happens under the same lock) |
| 19 | MINOR | "Hidden" temp claim false; AV sharing violations | Doc corrected; retry on sharing violations for move/delete |
| 20 | MINOR | `DropPlanner` I/O on UI thread; shared options dictionary | Documented "off UI thread"; options copied. 8.3 names: left to WP-11 (Windows-only) |
| 21 | MINOR | Log lost stack traces; second instance blocked | `ex.ToString()` on one line; `FileShare.ReadWrite` |
| 22 | MAJOR | `ITrigger.Start` couldn't report failure | `bool Start()` + `LastError` |
| 23 | MAJOR | No shared wheel type; single-path targets for multi-file drags | `IWheelView` (App) documented in C4; `GetTargetsFor(IReadOnlyList<string>)` with first-kind rule |
| 24 | MINOR | Renderer sync + ambiguous exception; clipboard could throw; no "nothing found" error | `GetPageCountAsync`, `PdfPasswordProtectedException`, `Task<bool> SetTextAsync`, `ConversionError.NoResult` |
| 25 | MINOR | CONTRACTS contradictions (C6 permutation vs subset, C1 exceptions, S4 example, C5 claims) | Rewritten; reference try/finally pattern added |

**Found while fixing (not in the review):** `File.Move(overwrite:false)` is check-then-rename on Linux, so 64 concurrent commits produced duplicate names (60 unique). Fixed with a per-folder lock in `SafeOutputWriter`; Windows was already atomic.

**Deferred (documented, not fixed):** INotifier takes one `pathToReveal` (first output is revealed); 8.3 short-name expansion (WP-11, Windows-only); settings-changed event (WP-11 holds settings in one field and recreates triggers).
